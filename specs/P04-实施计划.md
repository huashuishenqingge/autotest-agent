# P04 实施计划

依据：P04-模型适配与测试生成.md，用户2026-11-05回复“可以”批准草案及首次3次生成、每次2048输出词元限制。共享接口版本不变。

1. 04.1：新增models/adapter.py和测试。先运行缺模块失败，再实现配置、HTTPS兼容接口、超时/限长、usage、显式无重试和最多3次请求账本。测试用替身，不花真实额度。
2. 04.2：新增agents/generator.py和测试。提示中显式区分需求与不可信参考数据；接收只读相关测试且核对清单；严格JSON/身份/路径/语法检查；返回标准GenerateOutput。
3. 04.3：新增真实调用CLI示例和本机配置说明。先按固定源码与需求生成，复制已批准清单到独占副本，受控应用，再运行完整容器测试；记录模型版本、usage、提示版本、提案与运行证据。密钥不入产物。
4. 全套单元测试与本地模拟HTTP联调；独立审查及复跑；若密钥未配置则明确阻碍真实验收，保留可运行命令。更新唯一总表、阶段交接及Spec证据，上传功能分支；不进入P05。

实施裁定：沿用项目单一进度总表记录任务，不另建互相竞争的进度账本；在独立功能分支feature/model-generation工作，保留现有工作目录便于用户协作。新适配器采用标准库，不新增依赖。

首次真实调用计数以指定本地账本持久保存，尝试发请求前消耗一次，失败不退还；跨重启不重置。最多3次且不自动重试。账本损坏、并发占用均拒绝继续；用户不得以删除账本规避已批准限额。多电脑并行不共享本地账本，真实验收必须仅在一台电脑串行运行。
